# CV en ligne HTML CSS référencement

Projet de CV en ligne réalisé en HTML et CSS, corrigé à partir des commentaires de retour.

## Corrections intégrées

- Ajout d'une meta description.
- Titre de page plus clair et plus accessible.
- Utilisation de la balise `address` pour les informations de contact.
- Correction du titre principal avec `Développeur Web et Web Mobile` en `h1`.
- Ajout de balises `time` pour les dates, périodes et durées.
- Correction des accents et des textes mal encodés.
- Amélioration du placement des informations de contact.
- Ajout d'un lien GitHub dans le pied de page.
